# tiny home algarve tutorial

Interactive tutorial app for guiding a user through building `www.athomie.pt`, the future lead-generation website for the brand `tiny home algarve`.

The source material is the field manual in `docs/building-lead-generation-websites-with-codex-github-vercel-odoo.md` and the attached HTML file from the brief.

## Run

Open `index.html` in a browser.

No package install or dev server is required.

## What It Does

- Breaks the manual into guided build steps.
- Shows Learn, Do, and Verify tabs for each step.
- Provides step-specific Codex prompts.
- Tracks checklist progress in `localStorage`.
- Adapts the original manual from `tinyhomealgarve.com` to `www.athomie.pt`.
- Keeps the public brand name as `tiny home algarve`.
