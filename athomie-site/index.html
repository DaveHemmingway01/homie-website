Practical questions

FAQ for the first conversation.

Can I customise the tiny home?

Yes, but the first offer is intentionally limited. The goal is a controlled product, not an open-ended custom build.

Can this be installed anywhere in the Algarve?

Location, access, land conditions, services, and permissions need to be checked before any commitment.

Are prices final?

No final pricing claim is made on this page. Budget ranges are used to qualify the enquiry.

What makes HOMIE different from a cheap chalet?

HOMIE is positioned around timber construction, airtightness, insulation priorities, useful built-in functions, and a controlled options process.

Do I need land before contacting you?

No, but land status changes the conversation. If you already have land, access, services, and local constraints can be checked earlier.

Can HOMIE be used as a rental unit?

Possible rental use needs separate legal, planning, licensing, insurance, and financial checks. This page does not promise rental income.

What is included in the first model?

The first model is based on one bedroom, kitchen, bathroom, and compact living functions. Final inclusions should be confirmed in the brochure and scope.

Can I order outside Portugal?

Secondary enquiries outside Portugal can be qualified, but logistics, compliance, delivery, and local requirements need checking before any commitment.
