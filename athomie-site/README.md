# athomie.pt local landing page

Local-first landing page for `www.athomie.pt`, using the public brand direction `tiny home algarve` and HOMIE as the product name.

## Run

Open:

```text
athomie-site/index.html
```

No build step is required.

## Included

- Conversion-focused landing page
- English base copy
- Partial Portuguese, German, and Dutch language switching
- Lead form with local browser storage
- UTM / click ID attribution storage for later Odoo mapping
- Placeholder downloadable materials
- Process, model, materials, FAQ, trust, and content-strategy sections

## Not Included Yet

- Odoo CRM submission
- Real final brochures / floor plans
- Verified pricing
- Legal / planning permission claims
- Final production translations
- Analytics container IDs
